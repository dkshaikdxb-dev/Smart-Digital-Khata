## What is NOT in here, and must not be answered here

**The 267 undecided web/app differences.** Those are pairs where the two
surfaces say different things and nobody has ruled on whether that is a problem. They are
deliberately absent. Answering one in passing, because it turned up next to a row you were
reading, is how an undecided question gets settled by whoever happened to be looking —
which is the failure this whole apparatus exists to prevent. If you notice one and think it
is wrong, say so separately; it needs its own decision.

**The 14 intentional divergences.** The web and the app say
different things there on purpose, and each one is recorded with a reason.

**Anything LOCKED.** Already decided by a person. `scripts/i18n-decisions.json` has them.

## When an answer lands

An approved wording replaces the machine-authored one through the registry — the write
guard refuses it otherwise, which is the point. Re-run
`node scripts/i18n-review-snapshot.mjs --apply` so the snapshot tracks the approved text,
and `node scripts/i18n-review-packet.mjs --write` so this packet stops asking a question
that has been answered.
